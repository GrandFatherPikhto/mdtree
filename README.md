
## 🚀 Установка

Линк:

```bash
chmod 755 mdtree.poy
ln <mdtre_directory>mdtree.py ~/.local/bin/mdtree
```
Путь (zsh):

```bash
path+=("$HOME/.local/bin")
export PATH

```

Стандартный путь

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Скрипт распространяется свободно, без каких‑либо гарантий. Вы можете модифицировать его под свои нужды.
