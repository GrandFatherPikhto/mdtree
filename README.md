# mdtree — генератор структуры проекта с фильтрами и комментариями

**mdtree** — это утилита командной строки, которая рекурсивно обходит директорию проекта и формирует наглядное дерево файлов и папок в формате Markdown. Скрипт поддерживает:

- исключение ненужных файлов/папок по имени, пути, расширению или маске;
- белый список («разрешённые ветки») для изоляции конкретных поддиректорий;
- inline‑комментарии к любым элементам дерева;
- ограничение глубины обхода;
- вывод только директорий;
- автоматическое сохранение результата в Markdown‑файл с меткой времени.

## Установка и требования

Скрипт написан на **Python 3.6+** и использует только модули из стандартной библиотеки (`os`, `json`, `fnmatch`, `argparse`, `pathlib`, `datetime`, `math`). Дополнительных зависимостей не требуется.

Скопируйте файл `mdtree.py` в корень вашего проекта или в любое удобное место. Убедитесь, что он имеет права на исполнение (на Linux/macOS):

```bash
chmod +x mdtree.py
```

## Использование

Запустите скрипт из корневой директории вашего проекта:

```bash
python mdtree.py
```

По умолчанию будет прочитан файл конфигурации `tree_config.json` (если он существует) и выведено дерево в консоль. Если в конфиге указан `output_file`, результат также сохранится в указанный Markdown‑файл.

### Аргументы командной строки

| Аргумент | Описание |
|----------|----------|
| `-c`, `--config` | Путь к JSON‑файлу конфигурации (по умолчанию `tree_config.json`). |
| `-h`, `--help`   | Показать подробную справку и пример структуры конфига. |

Пример:

```bash
python mdtree.py --config my_settings.json
```

## Конфигурационный файл (JSON)

Скрипт ищет настройки в JSON‑файле. Все поля опциональны — при отсутствии используются значения по умолчанию.

| Поле | Тип | По умолчанию | Описание |
|------|-----|--------------|-----------|
| `depth` | число или `null` | `null` | Максимальная глубина рекурсии (начиная с 1). `null` — без ограничений. |
| `only_dirs` | boolean | `false` | Показывать только директории, игнорируя файлы. |
| `output_file` | строка или `null` | `null` | Путь для сохранения результата (например, `"docs/TREE.md"`). Если `null` — сохранять только в консоль. |
| `ignore_names` | список строк | `[".git", "__pycache__", ".venv"]` | Директории или файлы, которые нужно полностью исключить по имени (точное совпадение). |
| `ignore_paths` | список строк | `[]` | Исключение по относительному пути (например, `"tests/fixtures"`). Пути указываются с **прямыми слешами** `/`. |
| `ignore_extensions` | список строк | `[]` | Расширения файлов, которые следует скрыть (например, `[".pyc", ".log"]`). |
| `ignore_masks` | список строк | `[]` | Маски с подстановочным знаком `*` для исключения по имени файла/папки или по относительному пути. |
| `allow_only` | объект | `{}` | Белый список — задаёт, какие **непосредственные** подэлементы директории разрешены. Ключ — путь к родительской папке, значение — список имён разрешённых элементов. |
| `descriptions` | объект | `{}` | Комментарии к элементам. Ключ — имя элемента (файла или папки) или его относительный путь, значение — текст комментария. В дереве комментарий выводится после символа `#`. |

### Пример `tree_config.json`

```json
{
  "depth": 2,
  "only_dirs": false,
  "output_file": "docs/PROJECT_TREE.md",
  "ignore_names": [".git", ".DS_Store", "node_modules"],
  "ignore_paths": ["tmp/cache", "old_backup"],
  "ignore_extensions": [".log", ".tmp"],
  "ignore_masks": ["*.pyc", "test_*"],
  "allow_only": {
    "src": ["main.py", "utils"],
    "docs": ["README.md"]
  },
  "descriptions": {
    "src": "Исходные коды проекта",
    "src/main.py": "Точка входа в приложение",
    "docs": "Документация и руководства"
  }
}
```

### Пояснение полей

- **allow_only** позволяет изолировать часть дерева. В примере выше в папке `src` будут показаны только `main.py` и папка `utils` (все остальные элементы `src` игнорируются). Белый список действует только на один уровень вложенности.
- **descriptions** могут задаваться как точным именем элемента (например, `"README.md"`), так и относительным путём (например, `"docs/README.md"`). Если описания конфликтуют, приоритет у более специфичного пути.
- **ignore_paths** проверяются после разрешения `allow_only`. Это позволяет сначала отфильтровать через белый список, а потом уже исключить конкретные пути.
- **ignore_masks** применяются к имени элемента и к полному относительному пути (слеши `/`). Маска `"RAISE*"` скроет всё, что начинается на `RAISE`.

## Пример вывода

Консольный вывод (и содержимое Markdown-файла) выглядит так:

```text
.
├── src (12.3 КБ)          # Исходные коды проекта
│   ├── main.py (3.1 КБ)   # Точка входа в приложение
│   └── utils
│       └── helpers.py (1.2 КБ)
└── docs
    └── README.md (0.9 КБ) # Документация и руководства
```

При сохранении в Markdown-файл добавляется заголовок и временная метка:

````markdown
# Структура проекта

*Последнее обновление: 15.03.2026 14:30*

```text
.
├── src (12.3 КБ)          # Исходные коды проекта
│   ├── main.py (3.1 КБ)   # Точка входа в приложение
│   └── utils
│       └── helpers.py (1.2 КБ)
└── docs
    └── README.md (0.9 КБ) # Документация и руководства
```
````

## Примечания

- Размер файлов выводится в удобном формате (Б, КБ, МБ, ГБ).
- При ошибках чтения JSON используются стандартные настройки, выводится предупреждение в консоль.
- Пути в конфигурации должны использовать **прямые слеши `/`** (даже в Windows).
- Игнорирование `ignore_names` и `ignore_extensions` работает быстрее и проще, чем маски.
- Если `depth` ограничен, то вложенные элементы за пределами глубины не обрабатываются и не выводятся.

## 🚀 Как правильно выкатить её в систему (за 3 шага):
Чтобы вы могли запускать её из любой папки просто по имени (например, написав mdtree), сделайте следующее:
Шаг 1. Добавьте «шебанг» (shebang) в самую первую строку скрипта
Откройте ваш файл pytree.py и в самый верх (до всех импортов) вставьте строку, которая укажет системе использовать Python 3:

#!/usr/bin/env python3

Шаг 2. Перенесите скрипт в системную папку без расширения .py
Переименуйте файл (выберем для примера mdtree) и скопируйте его в локальный бинарник.

* Если хотите для себя лично (не нужны права root):

cp pytree.py ~/.local/bin/mdtree

* Если хотите глобально для всех пользователей системы:

sudo cp pytree.py /usr/local/bin/mdtree


Шаг 3. Сделайте файл исполняемым
Дайте файлу права на запуск, чтобы система не ругалась:

chmod +x ~/.local/bin/mdtree  # или /usr/local/bin/mdtree

Готово! Теперь, в какой бы папке и проекте вы ни находились, вам достаточно положить туда конфиг tree_config.json и просто набрать в терминале:

mdtree

И скрипт мгновенно обновит документацию!
Какое имя вам больше всего откликается? Если хотите, мы можем добавить в код красивый вывод флага --help, чтобы при наборе mdtree --help утилита сама кратко напоминала, как должен выглядеть JSON-конфиг!
